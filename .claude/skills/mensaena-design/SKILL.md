# Mensaena Design-Richtlinien

## Farbpalette
| Farbe | Hex | Verwendung |
|-------|-----|-----------|
| Primary | #1EAAA6 | Buttons, Links, Akzente |
| Primary Dark | #147170 | Hover, aktive States |
| Primary Light | #d0f5f3 | Hintergründe, Badges |
| Background | #EEF9F9 | Seiten-Hintergrund |
| Trust | #4F6D8A | Vertrauens-Badges |
| Emergency | #C62828 | Krisen-Modus, Fehler |
| Text Title | gray-900 | Überschriften |
| Text Body | gray-700 | Fließtext |
| Text Muted | gray-400 | Hinweise |

## Prinzipien
- Elegant, professionell, subtil
- NICHT erdrückend, NICHT verspielt
- Dezente Animationen, klare Hierarchie, viel Weißraum
- KEINE emerald-Farben → primary-* verwenden
- Mobile-first, responsive
